## 🔧 现在需要你做的配置

### 第1步：DCloud开发者中心
1. 访问：https://dev.dcloud.net.cn/uniLogin
2. 登录你的DCloud开发者账号
3. 开通"一键登录"服务
4. 充值付费（这是付费服务）
5. 获取 `ApiKey` 和 `ApiSecret`

### 第2步：更新云函数密钥
打开：`uniCloud-aliyun/cloudfunctions/getPhoneNumber/index.js`

替换第8-9行：
```javascript
apiKey: 'your_api_key_here',     // 🔴 改为实际的ApiKey
apiSecret: 'your_api_secret_here', // 🔴 改为实际的ApiSecret
```

### 第3步：云服务空间配置
1. 访问：https://unicloud.dcloud.net.cn/home
2. 创建阿里云服务空间
3. 在HBuilderX中关联云服务空间
4. 上传云函数：右键`getPhoneNumber`文件夹选择"上传云函数"

### 第4步：更新初始化代码
打开：`main.js`，替换第12行：
```javascript
env: 'your-env-id' // 🔴 改为你创建的云服务空间ID
```

### 第5步：隐私协议
打开：`utils/univerifyLogin.js`，替换第46-53行：
```javascript
"url": "https://your-domain.com/user-agreement", // 🔴 你的用户协议
"url": "https://your-domain.com/privacy-policy", // 🔴 你的隐私政策
```

## 🐞 常见问题

**问题1：按钮不显示**
- 检查 `supportUniverify` 是否为 `true`
- 在APP环境下会自动显示

**问题2：点击没反应**  
- 检查控制台日志
- 确认是否在真机环境

**问题3：授权界面不出现**
- 检查手机卡和网络
- 确认ApiKey配置正确

**问题4：获取手机号失败**
- 检查云函数是否上传成功
- 检查DCloud账户余额
