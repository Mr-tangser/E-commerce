# 🤖 AI客服入口使用指南

## 📱 已添加的AI客服入口

### 1. 个人中心页面 - 我的服务
**位置**：个人中心 → 我的服务 → AI客服
- 📍 在"意见反馈"和"客服热线"旁边
- 🎨 红色渐变图标，显眼易找
- 💬 点击直接跳转到AI客服页面

**使用方法**：
1. 打开APP，点击底部"我的"
2. 滚动到"我的服务"区域
3. 点击"🤖 AI客服"按钮

### 2. 首页导航菜单
**位置**：首页 → 横向滚动导航菜单 → AI客服
- 📍 在导航菜单的第一个位置
- 🎨 使用导航图标样式，与其他菜单项一致
- 💬 点击跳转到AI客服页面

**使用方法**：
1. 打开APP首页
2. 在横向滚动的导航菜单中找到"AI客服"
3. 点击进入AI客服页面

### 3. 购物车为空时的AI咨询
**位置**：购物车 → 空购物车状态 → 咨询AI按钮
- 📍 与"去购物"按钮并排显示
- 🎨 红色渐变样式，突出显示
- 💬 专门用于购物建议和商品咨询

**使用方法**：
1. 打开购物车页面（确保购物车为空）
2. 看到"购物车还是空的"提示
3. 点击"🤖 咨询AI"按钮获取购物建议

## 🔧 技术实现

### 跳转逻辑
所有AI客服入口都使用统一的跳转逻辑：
```javascript
uni.navigateTo({
  url: '/pages/AICustomerService/AICustomerService?from=来源页面',
  success: () => console.log('跳转成功'),
  fail: () => {
    // 降级处理：显示客服电话
    uni.showModal({
      title: '联系客服',
      content: '客服热线：400-123-4567',
      confirmText: '拨打电话'
    });
  }
});
```

### 来源标识
不同入口使用不同的来源标识：
- `from=my-service` - 个人中心我的服务
- `from=home-nav` - 首页导航菜单
- `from=empty-cart` - 空购物车咨询

## 🎯 用户体验优化

### 降级处理
如果AI客服页面跳转失败，系统会：
1. 显示客服联系方式
2. 提供拨打电话选项
3. 给出替代解决方案

### 上下文传递
购物车AI咨询会传递额外的上下文：
- `context=shopping-advice` - 表示用户需要购物建议
- 可用于AI客服自动提供购物相关的快捷问题
