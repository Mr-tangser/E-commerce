# PC端登录加密安全优化

## 概述

本系统实现了基于AES-256-CBC的对称加密方案，用于保护PC端管理系统的登录密码传输安全。

## 安全特性

### 1. 动态密钥生成
- **基础密钥**: 固定的应用密钥 `QinPinHui2024AdminSystem`
- **时间因子**: 基于5分钟粒度的时间戳
- **密钥生成**: MD5(基础密钥 + 时间戳)
- **密钥更新**: 每5分钟自动更新一次加密密钥

### 2. AES-256-CBC加密
- **算法**: AES-256-CBC
- **密钥长度**: 256位
- **IV**: 每次加密随机生成16字节IV
- **填充**: PKCS7标准填充

### 3. 时间戳验证
- **有效期**: 10分钟
- **防重放**: 结合验证码机制防止重放攻击
- **时钟偏差**: 允许10分钟的客户端时钟偏差

## 工作流程

### 前端加密流程
1. 获取当前时间戳
2. 基于时间戳生成动态密钥
3. 使用AES-256-CBC加密密码
4. 将加密数据和时间戳发送到后端

### 后端解密流程
1. 验证时间戳有效性（10分钟内）
2. 基于时间戳重新生成密钥
3. 解密密码数据
4. 使用解密后的密码进行身份验证

## API 变更

### 登录请求格式
```json
{
  "identifier": "用户名或邮箱",
  "password": "IV:加密后的密码",
  "captchaId": "验证码ID",
  "captchaCode": "验证码",
  "timestamp": 1699123456789
}
```

### 错误响应
- `请求已过期，请重新登录`: 时间戳超过10分钟
- `密码格式错误，请重新输入`: 解密失败
- `数据解密失败`: 密钥不匹配或数据损坏

## 安全优势

1. **传输安全**: 密码在网络传输中始终保持加密状态
2. **动态安全**: 加密密钥每5分钟自动更新
3. **时效性**: 加密数据有10分钟有效期，防止长期重用
4. **完整性**: 解密失败可检测数据篡改
5. **可扩展性**: 可轻松扩展到其他敏感数据加密


## 注意事项

1. **环境变量**: 生产环境应使用环境变量设置 `CRYPTO_SECRET_KEY`
2. **时钟同步**: 确保前后端服务器时间同步
3. **密钥管理**: 定期更换基础密钥
4. **日志安全**: 避免在日志中记录解密后的密码
