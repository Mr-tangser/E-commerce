## 🚨 **故障排除**

### 🔍 **常见问题**

#### **问题1：手机无法连接**
```
症状：AI客服显示离线，测试连接失败
解决：
1. 检查电脑和手机是否在同一WiFi
2. 确认电脑IP地址是否为 192.168.0.198
3. 重启AI服务
4. 检查防火墙设置
```

#### **问题2：服务未启动**
```bash
# 检查端口状态
netstat -ano | findstr ":3001"

# 预期看到：
TCP    0.0.0.0:3001    0.0.0.0:0    LISTENING    进程ID
```

#### **问题3：防火墙阻止**
```bash
# 重新添加防火墙规则
netsh advfirewall firewall add rule name="AI客服端口3001" dir=in action=allow protocol=TCP localport=3001

# 或者临时关闭防火墙测试
# 控制面板 → 系统和安全 → Windows Defender防火墙 → 启用或关闭
```

#### **问题4：IP地址变化**
```bash
# 重新获取IP地址
ipconfig | findstr "IPv4"

# 如果IP变化，需要更新配置文件：
# E-commerce_Mobile End/config/env.js
API_Global = '新IP地址:3000';
```
